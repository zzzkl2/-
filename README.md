# 腕管综合征图文预览 · 摸鱼绿

此文件夹可以直接用于 GitHub Pages，已适配项目站点的子目录地址。

## 设置步骤

1. 在 GitHub 新建公共仓库，建议名为 medical-articles，并勾选添加 README。
2. 选择 Add file → Upload files，将本文件夹里的文件和 assets 文件夹拖入上传区域。应让 index.html 直接出现在仓库首页，不要在外面再套一层文件夹。无需上传压缩包本身。
3. 保存提交到 main 分支。
4. 打开 Settings → Pages。
5. Build and deployment 中将 Source 设为 Deploy from a branch；Branch 选 main；文件夹选 /(root)；点击 Save。
6. 等待部署完成，在 Pages 设置页点击 Visit site。项目网址通常为 https://你的用户名.github.io/medical-articles/。
7. 确认使用 HTTPS 地址，并在 iPhone Safari 中打开。可复制图文，也可复制纯文字；手机目标编辑器能否完整接收排版，需要实际测试。

后续改稿可替换相应文件，保留图片文件夹结构。
